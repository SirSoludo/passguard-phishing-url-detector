16 Lexical Features
01url_lengthLonger URLs are more likely to be phishing.
02domain_lengthLong domain names suggest obfuscation.
03num_dotsExcess dots indicate subdomain nesting.
04num_subdomainsAttackers nest brands as subdomains.
05num_hyphensHyphens mimic brands: pay-pal-login.com
06num_underscoresRare in legit domains; suspicious when present.
07num_digitsHigh digit count → randomly generated domain.
08has_at_symbol@ tricks browser — everything before it is ignored.
09has_double_slash// in path is a known obfuscation trick.
10has_equals= in redirects can hide malicious destinations.
11has_question_markHeavy query strings used in credential harvesting.
12has_percent% encoding used to obfuscate phishing content.
13has_ip_addressIP instead of domain name is a strong phishing signal.
14num_special_charsCounts symbols unusual in legitimate URLs.
15uses_httpsHTTP (no TLS) is a risk flag.
16suspicious_keywordslogin, verify, secure, bank, update, etc.
